# 0X : Alternative non développée, Teachable Machine

[Teachable Machine](https://teachablemachine.withgoogle.com/train) est un outil Google équivalent à Edge Impulse pour entraîner un modèle sans code.

Un export vers microcontrôleur (Arduino/ESP32) existe via TensorFlow Lite for Microcontrollers, mais de façon moins directe qu'Edge Impulse : pas de bibliothèque Arduino générée automatiquement, intégration plus manuelle.

Piste non explorée dans PEGASE, gardée ici pour référence.
